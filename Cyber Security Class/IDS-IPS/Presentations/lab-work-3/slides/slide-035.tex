\begin{frame}[t,allowframebreaks]{Forwarding Ports with iptables}
  \fontsize{15}{18}\selectfont
  Port forwarding can be an extremely useful tool in certain situations, including the following:\par
  \begin{itemize}
    \item You move a server from one computer to another,
  \end{itemize}
  but your DNS entries have not yet been properly updated. You can also use port forwarding to temporarilymake such a change.\par
  \begin{itemize}
    \item You want a server to respond to multiple ports on a
  \end{itemize}
  single computer. You can set up the system to forward one port to another on the same system. Some servers can listen directly to multiple ports, though, which is often a simpler approach.\par
  \begin{itemize}
    \item You want to run an externally accessible server
  \end{itemize}
  within a \textcolor{CommandGreen}{\bfseries NAT}-protected network. You can set up the \textcolor{CommandGreen}{\bfseries NAT} router to forward traffic directed at one of its external ports to an internal system.\par
\end{frame}
