\begin{frame}[t]{Options Used in iptables Commands}
  \fontsize{14}{16}\selectfont
  \begin{itemize}
    \item Rules that allow packets to be filtered by the kernel are put in place by running the \textcolor{CommandGreen}{\bfseries iptables} command. When using the \textcolor{CommandGreen}{\bfseries iptables} command, specify the following options:
    \begin{itemize}
      \item Packet Type : Dictates what type of packets the command filters.
      \item Packet Source/Destination : Dictates which packets the command filters based on the source or destination of the packet.
      \item Target : Dictates what action is taken on packets matching the above criteria.
    \end{itemize}
    \item The options used with given \textcolor{CommandGreen}{\bfseries iptables} rule must be grouped logically, based on the purpose and conditions of the overall rule, in order for the rule to be valid.
  \end{itemize}
\end{frame}
