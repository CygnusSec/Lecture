\begin{frame}[t,allowframebreaks]{Options Used in iptables Commands}
  \fontsize{15}{18}\selectfont
  \begin{itemize}
    \item Rules that allow packets to be filtered by the kernel
  \end{itemize}
  are put in place by running the \textcolor{CommandGreen}{\bfseries iptables} command. When using the iptablescommand, specify the following options:\par
  \begin{itemize}
    \item Packet Type: Dictates what type of packets the
  \end{itemize}
  command filters.\par
  \begin{itemize}
    \item Packet Source/Destination: Dictates which
  \end{itemize}
  packets the command filters based on the source or destination of the packet.\par
  \begin{itemize}
    \item Target: Dictates what action is taken on packets
  \end{itemize}
  matching the above criteria.\par
  \begin{itemize}
    \item The options used with given \textcolor{CommandGreen}{\bfseries iptables} rule must be
  \end{itemize}
  grouped logically, based on the purpose and conditions of the overall rule, in order for the rule to be valid.\par
\end{frame}
