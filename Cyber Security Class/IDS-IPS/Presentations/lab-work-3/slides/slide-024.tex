The most frequently tested states are:\newline
\textcolor{WarningColor}{\bfseries ESTABLISHED}: The packet is part of a connection that has seen packets in both directions\newline
\textcolor{WarningColor}{\bfseries NEW}: The packet is the start of a new connection\newline
\textcolor{WarningColor}{\bfseries RELATED}: The packet is starting a new secondary connection. This is a common feature of such protocols such as an FTP data transfer, or an ICMP error.\newline
\textcolor{WarningColor}{\bfseries INVALID}: The packet couldn't be identified. Could be due to insufficient system resources, or ICMP errors that don't match an existing data flow.\\\hline
