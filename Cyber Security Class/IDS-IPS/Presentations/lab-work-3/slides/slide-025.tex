\begin{frame}[t,allowframebreaks]{Modules with Additional Match Options}
  \fontsize{15}{18}\selectfont
  \begin{itemize}
    \item To use a match option module, load the module by name using the -m
  \end{itemize}
  option, such as -m <module-name>(replacing <module-name>with the name of the module).\par
  \begin{itemize}
    \item state module: The state module (-m state --state ... match a packet with
  \end{itemize}
  the following connection states:\par
  \begin{itemize}
    \item \textcolor{WarningColor}{\bfseries ESTABLISHED}-The packet is associated with other packets in an
  \end{itemize}
  established connection.\par
  \begin{itemize}
    \item \textcolor{WarningColor}{\bfseries INVALID}-The packet can't be matched to a known connection, and
  \end{itemize}
  thus may be forged .\par
  \begin{itemize}
    \item \textcolor{WarningColor}{\bfseries NEW}-The packet is trying to establish a new connection .
    \item \textcolor{WarningColor}{\bfseries RELATED}-The packet is not part of an existing connection, but it's
  \end{itemize}
  related, such as an ICMP error packet . These connection states can be used in combination with one another by separating them with commas, such as -m state --state \textcolor{WarningColor}{\bfseries INVALID},\textcolor{WarningColor}{\bfseries NEW}.\par
  \begin{itemize}
    \item mac module-(-m mac ... ) Enables hardware MACaddress matching
  \end{itemize}
  with the following option:\par
  \begin{itemize}
    \item --mac-source -Matches a MACaddress of the network interface card
  \end{itemize}
  that sent the packet. To exclude a MAC address from a rule, place an exclamation point (!) after the --mac-source match option.\par
\end{frame}
