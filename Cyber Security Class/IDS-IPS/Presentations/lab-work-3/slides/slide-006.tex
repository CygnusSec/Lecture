\begin{frame}[t]{What Is iptables}
  \fontsize{14}{16}\selectfont
  \begin{itemize}
    \item The built-in chains for the \textcolor{CommandGreen}{\bfseries mangle} table are as follows:
    \begin{itemize}
      \item \textcolor{WarningColor}{\bfseries INPUT} --- Alters network packets targeted for the host.
      \item \textcolor{WarningColor}{\bfseries OUTPUT} --- Alters locally-generated network packets before they are sent out.
      \item \textcolor{WarningColor}{\bfseries FORWARD} --- Alters network packets routed through the host.
      \item \textcolor{WarningColor}{\bfseries PREROUTING} --- Alters incoming network packets before they are routed.
      \item \textcolor{WarningColor}{\bfseries POSTROUTING} --- Alters network packets before they are sent out.
    \end{itemize}
  \end{itemize}
\end{frame}
