\begin{frame}[t]{NIDS Mode}
  \fontsize{12}{14.5}\selectfont
  \vspace{0.1cm}
  NIDS (Network Intrusion Detection System) Mode is the standard operating mode of Snort for real-time intrusion detection. In this mode, Snort actively analyzes network traffic and generates alerts for suspicious or malicious activities based on predefined rules.
  \vspace{0.12cm}
  \begin{itemize}
    \item \textcolor{WarningColor}{Real-Time Threat Detection:} Monitors live traffic for signs of attacks.
    \item \textcolor{WarningColor}{Rule-Based Analysis:} Uses signature-based and anomaly-based rules to detect suspicious activity.
    \item \textcolor{WarningColor}{Alert Generation:} Triggers alerts on detecting potential threats or intrusions.
    \item \textcolor{WarningColor}{Network Visibility:} Provides insights into network behavior and security posture.
    \item \textcolor{WarningColor}{No Traffic Blocking:} Passive detection only---alerts without blocking or modifying traffic.
  \end{itemize}
\end{frame}
