\begin{frame}[t]{Packet Logger Mode}
  \fontsize{11.5}{14}\selectfont
  \vspace{0.1cm}
  Packet Logger Mode in Snort allows Snort to capture and log network packets to disk for later analysis. It is a passive mode where Snort captures raw packets without performing detection or generating alerts, but logs the traffic for future review.
  \vspace{0.12cm}
  \begin{itemize}
    \item \textcolor{WarningColor}{Stores Packets to Disk:} Saves network packets to files for later analysis.
    \item \textcolor{WarningColor}{Detailed Traffic Records:} Logs complete packet data, including headers and payload.
    \item \textcolor{WarningColor}{Supports Forensic Analysis:} Enables in-depth examination of past network activity.
    \item \textcolor{WarningColor}{Configurable Storage:} Allows specifying log formats and storage locations.
    \item \textcolor{WarningColor}{Useful for Audit Trails:} Creates a reliable record of network events for compliance or investigation.
  \end{itemize}
\end{frame}
