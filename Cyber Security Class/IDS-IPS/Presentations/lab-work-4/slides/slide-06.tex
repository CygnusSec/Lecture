  \begin{itemize}
    \item Snort modes:
    \begin{itemize}
      \item Snort is a multi-mode packet analysis tool
      \begin{itemize}
        \item Sniffer
        \item Packet Logger
        \item Forensic Data Analysis tool
        \item Network Intrusion Detection System
      \end{itemize}
    \end{itemize}
    \item Where did it come from?
    \begin{itemize}
      \item Developed out of the evolving need to perform network traffic analysis in both real-time and for forensic post processing
    \end{itemize}
  \end{itemize}
