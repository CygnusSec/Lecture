\begin{frame}[t]{Inline Mode (IPS)}
  \fontsize{11}{13.5}\selectfont
  In Inline Mode, Snort acts as an Intrusion Prevention System (IPS), actively blocking or modifying traffic in real-time to prevent malicious activity from reaching its target. Unlike in NIDS mode, where Snort only detects threats, Inline Mode allows Snort to take action, such as blocking or dropping harmful packets.
  \vspace{0.06cm}
  \begin{itemize}
    \item \textcolor{WarningColor}{Active Traffic Blocking:} Detects and blocks malicious traffic in real-time.
    \item \textcolor{WarningColor}{Intrusion Prevention:} Acts as a firewall, preventing attacks from reaching targets.
    \item \textcolor{WarningColor}{Customizable Rule Actions:} Rules can drop, reject, or log traffic based on threat level.
    \item \textcolor{WarningColor}{Packet Modification:} Modifies or removes harmful data before it reaches endpoints.
    \item \textcolor{WarningColor}{Enhanced Security Control:} Proactively protects network by stopping threats instantly.
  \end{itemize}
\end{frame}
