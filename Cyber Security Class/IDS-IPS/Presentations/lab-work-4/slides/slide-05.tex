\begin{frame}[t]{SNORT}
  \fontsize{17}{20.5}\selectfont
  \vspace{0.15cm}
  \begin{itemize}
    \item \textbf{Snort} is an open source network intrusion detection system, capable of performing real-time traffic analysis and packet logging on IP networks.
    \item \textbf{Snort} can be configured in two main modes: Intrusion Detection System (IDS), which passively alerts administrators about potential security issues, and Intrusion Prevention System (IPS), which actively blocks malicious traffic.
  \end{itemize}
\end{frame}
