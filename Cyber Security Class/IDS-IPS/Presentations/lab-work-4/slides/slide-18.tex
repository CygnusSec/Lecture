\begin{frame}[t]{Sniffer Mode}
  \fontsize{11.5}{14}\selectfont
  \vspace{0.1cm}
  Snort's Sniffer Mode is a passive mode where Snort captures and inspects network traffic without performing any analysis or detection. It is useful for monitoring network activity in real time, but it does not generate alerts or logs based on the traffic.
  \vspace{0.12cm}
  \begin{itemize}
    \item \textcolor{WarningColor}{Real-Time Packet Capture:} Captures network packets as they traverse the network.
    \item \textcolor{WarningColor}{Packet Display:} Shows raw packet data on the screen for immediate visibility.
    \item \textcolor{WarningColor}{No Analysis or Filtering:} Only captures packets, without applying any detection rules or analysis.
    \item \textcolor{WarningColor}{Network Monitoring:} Useful for basic traffic monitoring and troubleshooting.
    \item \textcolor{WarningColor}{Lightweight Operation:} Minimal processing overhead, as no detection engine is used.
  \end{itemize}
\end{frame}
