\begin{frame}[t]{nmap: Service Detection - How It Works and Options.}
  \begin{itemize}
    \setlength{\itemsep}{0.18cm}
    \item \BodyText{Using the \texttt{nmap-service-probes} database, Nmap identifies the service protocol, application, and version running on each port.}
    \item \BodyText{Examples include FTP, SSH, Telnet, and HTTP services such as vsftpd or Apache httpd.}
    \item \BodyText{Enable service detection with \texttt{-sV}:}
    \item \CommandText{sudo nmap -sV 172.16.1.10}
  \end{itemize}
\end{frame}
