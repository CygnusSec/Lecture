\begin{frame}{Main Contributions}

\begin{enumerate}
    \item A fair bandwidth model for station-level MAC access control.

    \item An active-time estimator that converts observed MAC activity into channel-utilization information.

    \item An adaptive CW update rule to improve per-station fairness.

    \item A TCP rate-adaptation mechanism using flow-level fair bandwidth estimation.

    \item Evaluation across five multi-hop ad hoc network scenarios.
\end{enumerate}
\end{frame}
